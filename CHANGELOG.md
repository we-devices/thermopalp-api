# Changelog

All notable changes to the Thermopalp Python API are documented here.

## 0.1.0 - 2026-08-07

- Added cross-platform USB CDC device discovery.
- Added synchronous connection and context-manager support.
- Added device metadata and settings access.
- Added temperature streaming and fixed-count sample collection.
- Added sample interval, channel mask, and persistent calibration controls.
- Added typed protocol and device exceptions.
